# Main results map

The main empirical results used in the dissertation are generated from the March to August pipeline.

The principal numerical files are:

```text
outputs/final_pipeline/thesis/generated/numbers.tex
outputs/final_pipeline/thesis/tables/
outputs/final_pipeline/reporting/final_thesis_claims_register.csv
```

The analysis covers weather forecast performance, probability calibration, comparison with Polymarket, linear probability pooling, conservative trading results, uncertainty estimates and forecast sensitivity.

The additional multi-contract trading comparison is stored separately under `outputs/trading_contrast_extension/`.

For the exact recorded main pipeline version, use the Git tag:

```text
msc-final-pipeline-final
```
