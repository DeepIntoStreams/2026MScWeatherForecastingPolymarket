# Final Repository Structure

## `config/`

Declared dates, models, data sources, seeds and evaluation choices.

## `src/weather_polymarket/`

Reusable empirical implementation.

## `notebooks/final/`

The ten reader-facing notebooks corresponding to the final thesis.

## `tests/`

Unit tests and mathematical reconciliation tests.

## `data/manifests/`

Source, sample, prediction and output manifests.

## `outputs/`

Only outputs from the clean final implementation.

## `docs/`

Current empirical design and reproducibility documentation.

The full exploratory history remains on the archive branch and is not
required to reproduce the final dissertation.
